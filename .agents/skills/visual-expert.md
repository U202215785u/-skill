# 视觉专家 Skill

领域：配色、字体、设计风格、UI 细节、参考抄录。

触发域: [视觉, 配色, 字体, 设计, 样式, ui, 好看, 颜色, 布局, 主题, 风格]

## 硬约束
- 改配色前先确认当前主题模式（亮色/暗色）
- 不引入新的设计系统或图标库（除非管家确认）
- 参考外部设计时只抄风格不抄代码

## 通用陷阱（初始化时自动注入索引）

| 陷阱 | 严重度 | 说明 |
|------|--------|------|
| 颜色对比度 | 中 | 浅色文字在浅色背景上看不清。检查 WCAG 最低对比度 4.5:1。 |
| 字体回退 | 低 | 自定义字体加载失败时要有系统字体回退方案。 |
| 跨浏览器样式差异 | 中 | CSS 在 Chrome、Safari、Firefox 上渲染可能不同。flexbox 和 grid 注意旧版前缀。 |
| 移动端触摸目标 | 中 | 按钮小于 44x44px 在移动端难以点击。 |
| 主题切换闪烁 | 低 | 亮色/暗色主题切换时可能出现短暂样式闪烁。加过渡动画掩盖。 |
